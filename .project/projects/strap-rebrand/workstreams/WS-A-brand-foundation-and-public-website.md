# Workstream: WS-A Brand Foundation and Public Website

## Objective

Establish the Strap identity and ship the supplied worktable website without weakening static marketing-route isolation.

## Owned Files/Areas

- Public brand assets, typography, tokens, and constants.
- Root metadata, SEO/structured data, public chrome, home page, and supporting marketing routes.
- Focused public-brand and metadata tests.

## Dependencies

- Supplied Strap HTML and SVG handoff.
- Existing marketing-route and static-layout boundaries.

## Risks

- Long-tail public copy remains under the previous brand.
- Remote font or asset behavior hurts performance or CSP.
- Responsive composition collapses or marketing routes load user state.

## Handoff Criteria

- Home and supporting public routes present one coherent Strap identity.
- Metadata and domain references agree on `strap.bvdm.ai`.
- Desktop/mobile/reduced-motion/focus behavior is ready for browser testing.
