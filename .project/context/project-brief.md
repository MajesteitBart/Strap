# Project Brief

## Problem
- Product problem: people using multiple AI tools repeatedly explain the same durable personal context, while ad hoc memory and notes become stale, noisy, or unsafe.
- Delivery problem: Creed has strong repository guidance but previously had no local project-contract layer for specs, workstreams, atomic tasks, state rollups, and evidence-backed closeout.

## Target Outcome
- Creed has a validated Delano runtime, repository-specific context pack, thin agent entrypoints, and a clean baseline on the private `main` branch.
- Future work can start from explicit project and task contracts without weakening the existing product, security, or verification rules.

## Scope Boundaries
- In scope: repository delivery context, Delano runtime assets, local lifecycle contracts, evidence, agent entrypoints, and workflow validation.
- Out of scope: user Creed content, application runtime state, secrets, product roadmap invention, framework migration, database changes, deployments, and external tracker synchronization.
