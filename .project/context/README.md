# Creed Context Pack

This folder is the durable, evidence-backed context layer for Creed delivery. Current source and migrations remain canonical for executable behavior; update these notes when product direction, architecture, constraints, testing policy, or delivery state changes materially.

Read by task area:

- `project-overview.md`: mission, delivery scopes, and current health.
- `project-brief.md`: the problem, current Delano outcome, and scope boundaries.
- `product-context.md`: users, core flows, product non-goals, and permission constraints.
- `tech-context.md`: stack, runtime assumptions, and integrations.
- `project-structure.md`: canonical repository and Delano boundaries.
- `system-patterns.md`: architecture and delivery patterns that must be reused.
- `project-style-guide.md`: naming, documentation, and review conventions.
- `gui-testing.md`: browser smoke routes and evidence requirements.
- `progress.md`: evidence-backed current delivery status and next actions.
- `source-materials.md`: provenance for the context pack.

Use `.agents/skills/manage-context/SKILL.md` for repairs. Do not leave template placeholders, hide contradictions, or promote assumptions to facts.
