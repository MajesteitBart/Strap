# Project Overview

## Mission
- Creed maintains one compact, curated personal context profile that every connected AI can read before responding and improve through permission-aware updates.
- The shared Company model extends the same file into governed workspaces without weakening Personal behavior or access boundaries.

## Active Delivery Scopes
- `delano-bootstrap`: retrofit and validate Delano as the repository's delivery contract and runtime.
- Future delivery scopes are created only from explicit product outcomes; the bootstrap does not invent a roadmap.

## Current Health
- The Next.js application, Supabase schema, tests, CLI package, and OpenWiki documentation already exist and run independently of Delano.
- Delano runtime files and the first project contract were installed on 2026-07-22. Validation evidence belongs in the project task logs and `progress.md`.
- High-risk surfaces include authentication boundaries, RLS and service-role access, agent instructions, Company permissions, billing/frozen-state behavior, and large orchestration files identified in `AGENTS.md`.
